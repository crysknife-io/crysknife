Welcome to Crysknife Security Demo

This demo shows how @RolesAllowed and @DenyAll annotations work with crysknife navigation and Keycloak authentication.

Test the navigation guards:

  • Public Page - accessible to everyone
  • Secure Page - requires "user" role (@RolesAllowed("user"))
  • Admin Page - requires "admin" role (@RolesAllowed("admin"))
