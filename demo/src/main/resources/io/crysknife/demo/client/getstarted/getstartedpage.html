Getting Started

Add Crysknife dependencies to your project and bootstrap the DI container.

Download Starter Projects

Get a ready-to-use project template with all dependencies and build configuration pre-configured.

Single Module

A minimal Hello World application with a single Maven module. Best for small projects and learning.

Multi Module

A Todo app with shared and client modules. Recommended for production projects with server-side code.

1. Add Maven Dependencies

pom.xml
<dependency>\n
  <groupId>io.crysknife</groupId>\n
  <artifactId>crysknife-core</artifactId>\n
  <version>0.10</version>\n
</dependency>\n
\n
<dependency>\n
  <groupId>io.crysknife</groupId>\n
  <artifactId>crysknife-processor</artifactId>\n
  <version>0.10</version>\n
  <scope>provided</scope>\n
</dependency>\n

2. Create the Application Entry Point

@GWT3EntryPoint is provided by gwt3-processors and marks the method that J2CL will call on application startup.

App.java
@Application\n
public class App {\n
\n
  @Inject\n
  private MyComponent component;\n
\n
  @GWT3EntryPoint\n
  public void onModuleLoad() {\n
    new AppBootstrap(this).initialize();\n
  }\n
\n
  @PostConstruct\n
  public void init() {\n
    DomGlobal.document.body.appendChild(\n
        component.getElement());\n
  }\n
}\n

3. Create a Component

MyComponent.java
@Singleton\n
@Templated("mycomponent.html")\n
public class MyComponent\n
    implements IsElement<HTMLDivElement> {\n
\n
  @Inject @DataField\n
  HTMLDivElement root;\n
\n
  @Override\n
  public HTMLDivElement getElement() {\n
    return root;\n
  }\n
}\n
mycomponent.html
<div data-field="root">\n
  <h1>Hello, Crysknife!</h1>\n
</div>\n
