ManagedInstance<T>

ManagedInstance<T> extends Provider<T> with lifecycle management. It tracks all @Dependent instances it creates and can destroy them via destroyAll() or destroy(instance), triggering @PreDestroy callbacks.

Dependent bean with lifecycle:

    @Dependent\n
    public class Worker {\n
        private static int counter = 0;\n
        private final int id = ++counter;\n
    \n
        @PreDestroy\n
        public void cleanup() {\n
            // called when destroyed\n
        }\n
    }\n

Injection point:

    @Inject ManagedInstance<Worker> workers;\n
    \n
    Worker w = workers.get();       // create\n
    workers.destroy(w);             // destroy one\n
    workers.destroyAll();           // destroy all\n
