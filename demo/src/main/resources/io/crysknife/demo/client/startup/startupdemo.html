@Startup

A bean annotated with @Startup is initialized eagerly when the application starts, not lazily when first injected. Combined with @PostConstruct, this is useful for initialization logic that must run at application boot.

Eager bean:

    @ApplicationScoped\n
    @Startup\n
    public class EagerService {\n
    \n
        @Inject StartupLog log;\n
    \n
        @PostConstruct\n
        public void init() {\n
            log.record("EagerService initialized");\n
        }\n
    }\n

Injection point:

    @Inject StartupLog log;\n
    // log already has entries — EagerService ran at startup!\n
