@Produces

Producer methods create beans programmatically. The @Produces annotation marks a method whose return value becomes a CDI-managed bean. The scope annotation on the method controls the bean lifecycle.

Producer class:

    @ApplicationScoped\n
    public class ServiceProducer {\n
    \n
        @Produces @Singleton\n
        public RandomIdService produceRandomIdService() {\n
            return new RandomIdService();\n
        }\n
    \n
        @Produces @Dependent\n
        public AppConfig produceAppConfig() {\n
            return new AppConfig();\n
        }\n
    }\n

Injection point:

    @Inject RandomIdService idService1;\n
    @Inject RandomIdService idService2;\n
    @Inject AppConfig config1;\n
    @Inject AppConfig config2;\n
