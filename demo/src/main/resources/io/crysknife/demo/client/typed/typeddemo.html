@Typed

The @Typed annotation restricts the bean types that a bean exposes for injection. Dog is @Typed(Dog.class), so it can only be injected as Dog, not as Animal. Cat has no restriction and is the only bean visible as Animal.

Restricted bean:

    @ApplicationScoped\n
    @Typed(Dog.class)\n
    public class Dog implements Animal {\n
        public String sound() { return "Woof"; }\n
    }\n

Unrestricted bean:

    @ApplicationScoped\n
    public class Cat implements Animal {\n
        public String sound() { return "Meow"; }\n
    }\n

Injection points:

    @Inject Dog dog;      // OK — Dog.class is in @Typed\n
    @Inject Animal animal; // Gets Cat — Dog is not visible as Animal\n
