@InterceptorBinding + @AroundInvoke

This demo shows Jakarta Interceptors in action. The GreetingService has methods annotated with @Logged (a custom @InterceptorBinding). The LoggingInterceptor intercepts those calls via @AroundInvoke.

Interceptor binding:

    @InterceptorBinding\n
    @Retention(RetentionPolicy.RUNTIME)\n
    @Target({ElementType.METHOD, ElementType.TYPE})\n
    public @interface Logged {}\n

Interceptor:

    @ApplicationScoped\n
    @Interceptor\n
    @Logged\n
    public class LoggingInterceptor {\n
        @AroundInvoke\n
        public Object intercept(InvocationContext ctx) throws Exception {\n
            // before\n
            Object result = ctx.proceed();\n
            // after\n
            return result;\n
        }\n
    }\n

Intercepted service:

    @ApplicationScoped\n
    public class GreetingService {\n
        @Logged\n
        public String greet(String name) {\n
            return "Hello, " + name + "!";\n
        }\n
    }\n
