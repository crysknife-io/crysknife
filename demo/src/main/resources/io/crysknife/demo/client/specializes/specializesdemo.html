@Specializes

A @Specializes bean replaces its parent bean entirely. When you inject the parent type, the container provides the specialized child instead. Unlike @Alternative, specialization is always active — no configuration needed.

Parent bean:

    @ApplicationScoped\n
    public class BaseService {\n
        public String getName() {\n
            return "BaseService";\n
        }\n
    }\n

Specialized bean:

    @ApplicationScoped\n
    @Specializes\n
    public class SpecializedService extends BaseService {\n
        @Override\n
        public String getName() {\n
            return "SpecializedService";\n
        }\n
    }\n

Injection point:

    @Inject BaseService service;\n
    // Actually gets SpecializedService!\n
