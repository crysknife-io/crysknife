@Decorator + @Delegate

This demo shows CDI Decorators in action. The UpperCaseGreeterDecorator wraps the SimpleGreeter bean. When you inject the Greeter interface, you get the decorator which transforms the result to uppercase. Injecting the concrete SimpleGreeter type bypasses the decorator.

Interface:

    public interface Greeter {\n
        String greet(String name);\n
    }\n

Original bean:

    @ApplicationScoped\n
    public class SimpleGreeter implements Greeter {\n
        public String greet(String name) {\n
            return "Hello, " + name + "!";\n
        }\n
    }\n

Decorator:

    @ApplicationScoped\n
    @Decorator\n
    @Priority(1000)\n
    public class UpperCaseGreeterDecorator implements Greeter {\n
        @Inject @Delegate\n
        Greeter delegate;\n
    \n
        public String greet(String name) {\n
            return delegate.greet(name).toUpperCase();\n
        }\n
    }\n
