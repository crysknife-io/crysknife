WebSocket Client

1. Define a @ClientEndpoint bean:

    @ClientEndpoint\n
    @Singleton\n
    public class ChatEndpoint {\n
    \n
        @OnOpen\n
        public void onOpen(Session session) {\n
            session.getBasicRemote()\n
                .sendText("hello");\n
        }\n
    \n
        @OnMessage\n
        public void onMessage(String message) {\n
            // handle incoming message\n
        }\n
    \n
        @OnClose\n
        public void onClose(CloseReason reason) {\n
            // handle disconnect\n
        }\n
    \n
        @OnError\n
        public void onError(Throwable error) {\n
            // handle error\n
        }\n
    }\n

2. Inject WebSocketConnector and connect:

    @Inject\n
    WebSocketConnector<ChatEndpoint> connector;\n
    \n
    connector\n
        .baseUri("ws://localhost:8080/chat")\n
        .connect();\n

The framework generates the WebSocket wiring at compile time — @OnOpen, @OnMessage, @OnClose, and @OnError callbacks are bound automatically.
