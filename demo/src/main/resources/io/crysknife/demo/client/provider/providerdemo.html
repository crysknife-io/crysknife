Provider<T>

ManagedInstance<T> implements Provider<T> and gives you lazy, on-demand bean creation with lifecycle management. Each call to provider.get() on a @Dependent bean returns a new instance.

Dependent bean:

    @Dependent\n
    public class ExpensiveService {\n
        private final int instanceId = new Random().nextInt(10000);\n
    }\n

Injection point:

    @Inject ManagedInstance<ExpensiveService> provider;\n
    \n
    // Each call creates a new instance:\n
    ExpensiveService a = provider.get();\n
    ExpensiveService b = provider.get();\n
    // a.instanceId != b.instanceId\n
Click "provider.get()" to create instances
