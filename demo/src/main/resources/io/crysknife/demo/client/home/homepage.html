Flexible HTML5 Templating

Use standard HTML files as templates. Bind Java fields to DOM elements with @DataField. No custom widget toolkit required.

CustomerForm.html
<div class="customer-form">\n
  <input id="name" type="text"\n
         placeholder="Your Name">\n
  <input id="phone" type="tel"\n
         placeholder="Phone Number">\n
  <button id="saveBtn">Save</button>\n
</div>\n
CustomerForm.java
@Singleton\n
@Templated("CustomerForm.html")\n
public class CustomerForm\n
    implements IsElement<HTMLDivElement> {\n
\n
  @Inject @DataField\n
  HTMLInputElement name;\n
\n
  @Inject @DataField\n
  HTMLInputElement phone;\n
\n
  @Inject @DataField\n
  HTMLButtonElement saveBtn;\n
}\n

Simple DOM Element Injection and Binding

Attach event handlers with a single annotation. @EventHandler wires click, input, and other DOM events directly to Java methods.

CustomerForm.java
@Templated @Page\n
public class CustomerForm\n
    implements IsElement<HTMLDivElement> {\n
\n
  @Inject @DataField\n
  HTMLInputElement name;\n
\n
  @Inject @DataField\n
  HTMLButtonElement saveBtn;\n
\n
  @EventHandler("saveBtn")\n
  public void onSave(\n
      @ForEvent("click") MouseEvent e) {\n
    DomGlobal.alert("Hello, " + name.value);\n
  }\n
}\n

Bidirectional Model ↔ UI Binding

Two-way data binding keeps your model and UI fields in sync automatically. Change the form — the model updates. Change the model — the form updates.

CustomerForm.java
@Templated @Page\n
public class CustomerForm\n
    implements IsElement<HTMLDivElement> {\n
\n
  @Inject @AutoBound\n
  DataBinder<Customer> binder;\n
\n
  @Inject @Bound @DataField\n
  HTMLInputElement name;\n
\n
  @Inject @Bound @DataField\n
  HTMLInputElement phone;\n
\n
  @EventHandler("saveBtn")\n
  public void onSave(\n
      @ForEvent("click") MouseEvent e) {\n
    // customer already reflects form contents\n
    Customer c = binder.getModel();\n
    sendToServer(c);\n
  }\n
}\n

Typesafe CDI Events

Fire and observe strongly-typed events across beans. Decoupled, type-safe communication — no event bus boilerplate.

OrderService.java
@Singleton\n
public class OrderService {\n
\n
  @Inject\n
  Event<OrderPlaced> orderEvent;\n
\n
  public void placeOrder(Order order) {\n
    // process order...\n
    orderEvent.fire(\n
        new OrderPlaced(order));\n
  }\n
}\n
OrderList.java
@Templated\n
public class OrderList\n
    implements IsElement<HTMLDivElement> {\n
\n
  void onNewOrder(\n
      @Observes OrderPlaced event) {\n
    // automatically called when\n
    // OrderPlaced is fired\n
    refreshList();\n
  }\n
}\n

Jakarta Interceptors

Cross-cutting concerns with @InterceptorBinding and @AroundInvoke. Logging, validation, caching — without touching business logic.

LoggingInterceptor.java
@InterceptorBinding\n
@Target({TYPE, METHOD})\n
@Retention(RUNTIME)\n
public @interface Logged {}\n
\n
@Logged @Interceptor\n
public class LoggingInterceptor {\n
\n
  @AroundInvoke\n
  public Object log(InvocationContext ctx)\n
      throws Exception {\n
    console.log("Calling: "\n
        + ctx.getMethod().getName());\n
    return ctx.proceed();\n
  }\n
}\n
\n
// Usage: annotate any bean method\n
@Singleton\n
public class MyService {\n
  @Logged\n
  public String process() {\n
    return "done";\n
  }\n
}\n

CDI Decorators

Transparent interface wrapping with @Decorator and @Delegate. Chain multiple decorators with @Priority ordering.

TimedGreeter.java
@Decorator\n
public abstract class TimedGreeter\n
    implements Greeter {\n
\n
  @Inject @Delegate\n
  Greeter delegate;\n
\n
  @Override\n
  public String greet(String name) {\n
    double start = currentTimeMillis();\n
    String result = delegate.greet(name);\n
    double ms = currentTimeMillis() - start;\n
    console.log("Took " + ms + "ms");\n
    return result;\n
  }\n
}\n
