@Alternative

An @Alternative bean provides an alternative implementation that can replace the default bean. When an alternative is enabled, it takes priority over the default implementation for the same interface.

Interface:

    public interface Greeting {\n
        String greet();\n
    }\n

Default implementation:

    @ApplicationScoped\n
    public class DefaultGreeting implements Greeting {\n
        public String greet() {\n
            return "Default greeting";\n
        }\n
    }\n

Alternative implementation:

    @Alternative\n
    @ApplicationScoped\n
    public class FriendlyGreeting implements Greeting {\n
        public String greet() {\n
            return "Hey friend!";\n
        }\n
    }\n
